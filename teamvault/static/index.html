Folder link

Folder on this computer

Everything readable inside it, including subfolders. Images, video, archives and program files are skipped automatically.

Worth knowing

Files in a folder do not carry Drive's sharing settings, so this knowledge base cannot be split up per person afterwards: everyone you send it to gets all of it. If different people need to see different parts, use one of the Drive options, where each person's copy is matched to what they can already open.
